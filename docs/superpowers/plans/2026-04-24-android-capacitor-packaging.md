# Android Capacitor Packaging — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Package the Tambola React/Vite web app as an Android app (APK/AAB) using Capacitor, ready for Play Store publishing.

**Architecture:** Capacitor wraps the Vite build output (`dist/`) in a native Android WebView. The web app code is unchanged. Capacitor plugins handle StatusBar and SplashScreen native APIs. The Android project lives in `android/` and is generated/synced by Capacitor CLI.

**Tech Stack:** React 19, Vite 8, Capacitor 7, Android SDK, Gradle

---

## Prerequisites (user responsibility)

Before Task 5 (Android build), the user needs:
- **JDK 17+** — `brew install openjdk@17` (not currently installed)
- **Android Studio** — provides Android SDK, build tools, and emulator
- **ANDROID_HOME** — set in shell profile (e.g. `export ANDROID_HOME=~/Library/Android/sdk`)

Tasks 1–4 can run without these. Task 5+ requires them.

### Task 3: Add native bridge initialization

**Files:**
- Create: `src/capacitor-init.js`
- Modify: `src/main.jsx`

- [ ] **Step 1: Create `src/capacitor-init.js`**

```js
import { Capacitor } from '@capacitor/core';

export async function initNativeBridge() {
  if (!Capacitor.isNativePlatform()) return;

  const { StatusBar, Style } = await import('@capacitor/status-bar');
  const { SplashScreen } = await import('@capacitor/splash-screen');

  StatusBar.setStyle({ style: Style.Dark });
  StatusBar.setBackgroundColor({ color: '#0c0c11' });
  SplashScreen.hide();
}
```

This file dynamically imports native plugins only on native platforms, so the web build is unaffected.

- [ ] **Step 2: Update `src/main.jsx` to call init**

```jsx
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import App from './App.jsx'
import { initNativeBridge } from './capacitor-init.js'

initNativeBridge();

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <App />
  </StrictMode>,
)
```

### Task 5: Generate launcher icons

**Files:**
- Create: `resources/icon.png` (source icon, 1024x1024)
- Modify: `android/app/src/main/res/mipmap-*` directories

- [ ] **Step 1: Create a simple launcher icon source**

Since the existing `favicon.svg` is a complex purple lightning bolt SVG, we need to create a proper 1024x1024 PNG for Android. We'll create a simple, identifiable icon using the app's branding.

Use an HTML canvas approach to generate the icon:

```bash
cd /Users/valerianpereira/bms/india/playground/tambola
mkdir -p resources
```

Create `resources/generate-icon.html` — a small HTML file that renders a 1024x1024 canvas icon and lets you download it. Open it in a browser to generate `icon.png`:

```html
<!DOCTYPE html>
<html><body>
<canvas id="c" width="1024" height="1024"></canvas>
<script>
const c = document.getElementById('c');
const ctx = c.getContext('2d');
// Background: BMS red gradient
const g = ctx.createLinearGradient(0, 0, 1024, 1024);
g.addColorStop(0, '#ff5264');
g.addColorStop(1, '#dc354b');
ctx.fillStyle = g;
ctx.beginPath();
ctx.roundRect(0, 0, 1024, 1024, 224);
ctx.fill();
// Letter T
ctx.fillStyle = '#fff';
ctx.font = 'bold 620px Inter, sans-serif';
ctx.textAlign = 'center';
ctx.textBaseline = 'middle';
ctx.fillText('T', 512, 540);
// Download link
const a = document.createElement('a');
a.download = 'icon.png';
a.href = c.toDataURL('image/png');
a.textContent = 'Download icon.png';
a.style = 'display:block;text-align:center;margin:20px;font-size:24px';
document.body.appendChild(a);
</script>
</body></html>
```

Open in browser, click "Download icon.png", and save to `resources/icon.png`.

- [ ] **Step 1: Update AndroidManifest.xml**

Ensure the following attributes are set in `AndroidManifest.xml`:

In the `<activity>` tag, set:
```xml
android:screenOrientation="portrait"
android:configChanges="orientation|keyboardHidden|keyboard|screenSize|locale|smallestScreenSize|screenLayout|uiMode"
android:launchMode="singleTask"
```

These keep the app in portrait mode and prevent WebView reloads on configuration changes.

### Task 9: Document release build and signing

**Files:**
- Create: `docs/RELEASE.md`

- [ ] **Step 1: Write release build documentation**

Create `docs/RELEASE.md` with these instructions:

```markdown
# Release Build — Tambola Android App

## Prerequisites

- JDK 17+ installed
- Android SDK installed (via Android Studio)
- `ANDROID_HOME` environment variable set

## Generate a signing keystore (one-time)

```bash
keytool -genkey -v -keystore tambola-release.keystore \
  -alias tambola -keyalg RSA -keysize 2048 -validity 10000
```

Store the keystore file and passwords securely. You will need them for every release.

## Configure signing in Gradle

Create `android/keystore.properties` (do NOT commit this file):

```properties
storeFile=../tambola-release.keystore
storePassword=YOUR_STORE_PASSWORD
keyAlias=tambola
keyPassword=YOUR_KEY_PASSWORD
```

Add to `android/app/build.gradle` above `android {`:

```groovy
def keystorePropertiesFile = rootProject.file("keystore.properties")
def keystoreProperties = new Properties()
if (keystorePropertiesFile.exists()) {
    keystoreProperties.load(new FileInputStream(keystorePropertiesFile))
}
```

Inside `android { }`, add:

```groovy
signingConfigs {
    release {
        storeFile file(keystoreProperties['storeFile'] ?: 'debug.keystore')
        storePassword keystoreProperties['storePassword'] ?: ''
        keyAlias keystoreProperties['keyAlias'] ?: ''
        keyPassword keystoreProperties['keyPassword'] ?: ''
    }
}
buildTypes {
    release {
        signingConfig signingConfigs.release
        minifyEnabled true
        proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
    }
}
```

## Build release AAB

```bash
npm run build && npx cap sync android
cd android
./gradlew bundleRelease
```

Output: `android/app/build/outputs/bundle/release/app-release.aab`

## Upload to Play Store

1. Go to https://play.google.com/console
2. Create your app listing
3. Upload the `.aab` file under "Production" > "Create new release"
4. Fill in store listing details (screenshots, description, etc.)
5. Submit for review
```
